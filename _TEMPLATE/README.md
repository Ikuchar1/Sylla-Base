Copy this whole folder to start a new course:

    cp -R _TEMPLATE <TERM>/DEPT-###

Then fill in `<TERM>/DEPT-###/course.md` with the meeting schedule and exam dates —
that's what "what did I miss?" checks against, and add the course to `## Current term`
in the root `CLAUDE.md`.

You write in `lectures/`, `materials/`, and `assignments/`. Claude writes in `wiki/`
and `sessions/`.

Open this folder in Obsidian (**Open folder as vault**) to see only this course.
