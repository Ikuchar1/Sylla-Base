Your actual assignment files go here — notebooks, drafts, submitted docs, graded PDFs,
quiz note sheets. One folder per assignment keeps it from turning into a pile:

    homework/hw-1/            notebook + data for one homework
    in-class/<topic>/         in-class exercises, grouped by topic (gans/, vaes/)
    quizzes/quiz-1.md         quiz questions + your answers
    papers/summary-1/         writing: prompt, your draft, reference draft, final
    discussion/week-01-<slug>/  weekly posts: post.md, examples.md, response.md

This is a RAW folder. Claude reads it; `/homework-mode` only writes into the TODO cells
of the file you're working on together, and draft files it creates for writing.

The tracking page for each assignment — what it asks, which concepts it needs,
what's done — lives in `wiki/assignments/`.
